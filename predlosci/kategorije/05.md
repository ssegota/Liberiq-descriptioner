# PDP template opisa: Lifestyle

## Koji template se koristi

Template se bira prema vrsti proizvoda, ne prema kategoriji. U kategoriji Lifestyle koriste se ovi templateovi:

| **Template** | **Za proizvode** |
|:---|:---|
| Template J: Lifestyle proizvodi | Boce i šalice, obuća, hipoalergeni nakit, aromaterapija, sport i rekreacija |
| Template A: Dodaci prehrani | Dodaci prehrani za žensko i muško zdravlje, sportaše, bio ljekarna |
| Template B: Kozmetika i dermokozmetika | Oralna higijena i depilacija |
| Template K: Bezreceptni lijekovi i homeopatski proizvodi | Homeopatski proizvodi |
