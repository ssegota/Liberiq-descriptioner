# PDP template opisa: Zdravlje

## Koji template se koristi

Template se bira prema vrsti proizvoda, ne prema kategoriji. U kategoriji Zdravlje koriste se ovi templateovi:

| **Template** | **Za proizvode** |
|:---|:---|
| Template A: Dodaci prehrani | Većina proizvoda: dodaci prehrani po tegobama (imunitet, probava, san, srce, oči…) |
| Template B: Kozmetika i dermokozmetika | Dermokozmetika (npr. Cicaplast) i njega iritirane kože |
| Template D: Medicinski uređaji | Medicinski proizvodi: fiziološke otopine, flasteri, sprejevi za nos |
| Template K: Bezreceptni lijekovi i homeopatski proizvodi | Bezreceptni lijekovi (npr. Wick VapoRub) |
