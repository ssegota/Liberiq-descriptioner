# PDP template opisa: Rehabilitacijski program

## Koji template se koristi

Template se bira prema vrsti proizvoda, ne prema kategoriji. U kategoriji Rehabilitacijski program koriste se ovi templateovi:

| **Template** | **Za proizvode** |
|:---|:---|
| Template F: Ortoze, steznici, kompresivne čarape i kućna njega | Steznici, ortoze, kompresivne čarape, kućna njega bolesnika |
| Template G: Pelene i ulošci za inkontinenciju | Pelene i ulošci za inkontinenciju |
